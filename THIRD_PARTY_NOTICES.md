# Third-party software and assets

Python dependencies and exact versions are recorded in `uv.lock`; install them under their respective licenses. The application uses Flask (BSD-3-Clause), Jinja2 (BSD-3-Clause), Werkzeug (BSD-3-Clause), SQLAlchemy (MIT), Flask-SQLAlchemy (BSD-3-Clause), Flask-Login (MIT), Flask-WTF (BSD-3-Clause), Flask-Migrate (MIT), Alembic (MIT), Pillow (MIT-CMU), qrcode (BSD-3-Clause), psycopg (LGPL-3.0), Gunicorn (MIT), python-dotenv (BSD-3-Clause). Development tools include pytest (MIT), Playwright (Apache-2.0), ReportLab (BSD), pypdf (BSD-3-Clause).

Vendored browser assets, retained unchanged so classroom operation does not require a CDN:

| Asset | Version | Upstream | License file |
|---|---|---|---|
| Bootstrap CSS | 5.3.8 | https://github.com/twbs/bootstrap | `app/static/vendor/bootstrap-LICENSE.txt` (MIT) |
| Chart.js | 4.5.1 | https://github.com/chartjs/Chart.js | `app/static/vendor/chartjs-LICENSE.txt` (MIT) |
| jsQR | 1.4.0 | https://github.com/cozmo/jsQR | `app/static/vendor/jsqr-LICENSE.txt` (Apache-2.0) |

jsQR has an older upstream release; it was selected as a small, offline decoder with real browser fixture verification rather than relying on the browser-specific BarcodeDetector API. Re-evaluate its maintenance status before wider production use. QR generation uses qrcode 8.2. Neither library sends camera frames to a server.

Demo product illustrations and placeholder SVG are original geometric assets generated by this project's code (`app/cli.py`); they are fictional and carry no third-party branding. All business records are synthetic. No external product photographs are used.

Significant AI assistance is recorded in `docs/ai-usage.md`.

Receipt importing also uses pypdf (BSD-3-Clause), pypdfium2 (Apache-2.0/BSD-3-Clause, with PDFium's bundled third-party notices supplied by its package), and the separately installed Tesseract OCR executable (Apache-2.0). Upstreams: https://github.com/py-pdf/pypdf , https://github.com/pypdfium2-team/pypdfium2 , https://github.com/tesseract-ocr/tesseract . No cloud OCR service or mailbox data transfer is used.
